# 🧠 Ultra Smart Notes V5

A modern desktop note-taking application built with **Python** and **PyQt5**.

---

## ✨ Features

- 📂 Folder Manager
- ⭐ Favorite Notes
- 📌 Pin Notes
- 🎨 Multiple Themes (Dark, Light, Blue, Red, Hacker)
- 🔒 Password Protection
- 💾 Auto Save
- 🗜 ZIP Backup & Restore
- 📊 Statistics Dashboard
- 📄 Export TXT
- 📕 Export PDF
- 📅 Date Insert
- ✅ Todo List
- ♻ Recycle Bin
- 🕒 Session Restore
- 📋 Copy & Paste
- 🔤 Rich Text (Bold, Italic, Underline)

## 🚀 Installation

```bash
git clone https://github.com/SyahirAsyam/SmartNotesUltra.git

cd SmartNotesUltra

pip install -r requirements.txt

python ultra_smart_notes_v4.py
```
